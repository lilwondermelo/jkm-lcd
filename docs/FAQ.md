# FAQ

**Почему в PWA не открывается камера?**
Браузеры разрешают `getUserMedia` только на HTTPS или на localhost. По
`http://<HOST>:8090` кнопка «Сканировать QR-код» может не работать — наведите
на QR камеру телефона: откроется ссылка `/pair?code=…`, и PWA привяжется сама.
В APK сканер работает без HTTPS.

**На другом кулере другой VID/PID?**
Да. `1a86:5722` и `9600 8N1` — параметры одной модели. Проверьте `lsusb` и
документацию устройства; при необходимости поправьте `VID/PID` в
`server/display.py` и скорость.

**Почему нет яркости?**
Прошивка не поддерживает команду яркости. Выключение — остановка кадров,
включение — новый handshake.

**Можно ли без root?**
Да, если не нужна мощность CPU (RAPL). Уберите `User=root` из юнита; тогда
сервер не будет отправлять кадры, пока нет данных о питании, либо поправьте
`server/main.py`, чтобы не ждать RAPL.

**Где токен?**
Нигде в репозитории. Device-токены — в `~/.local/state/jkm-lcd/pair.json`
(600), настройки — в `~/.config/jkm-lcd/`.

**Это официальное приложение JKM?**
Нет, проект не связан с производителем кулера.
